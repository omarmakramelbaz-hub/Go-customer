Opening splash video assets

Preferred asset:
- opening_hq.mp4
- High-quality H.264/AAC MP4 used automatically when bundled with the app.

Fallback asset:
- part_00.b64 through part_07.b64
- Legacy Base64 chunks are assembled in memory and played only when opening_hq.mp4 is unavailable.

The splash screen plays once, with audio enabled, then holds the final frame for one extra second before navigation.
